# AMBA AHB-Lite Master–Slave Verification

## Overview
This project implements a simplified AMBA AHB-Lite master and slave using Verilog, with an object-oriented SystemVerilog testbench for functional verification.

## Design
- AHB-Lite master RTL
- AHB-Lite slave RTL
- AHB bus interface
- Transaction-based verification environment

## Verification Components
- Transaction class
- Generator
- Driver
- Monitor
- Scoreboard
- Test and top-level testbench

## Tools
- AMD Vivado 2025.2
- Verilog
- SystemVerilog

## Current Status
RTL and testbench development are in progress. Simulation results will be added after successful compilation and verification.

## Future Improvements
- Add wait-state testing
- Add error-response testing
- Improve protocol checking and functional coverage
